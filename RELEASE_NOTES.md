# Pulso CG 2.2.0

- Avisos de versiones nuevas dentro de la aplicación y notificación del sistema.
- Descarga con progreso y botón Reiniciar y actualizar.
- Consulta al abrir la app, cada seis horas y desde Ayuda → Buscar actualizaciones.
- Sin instalación automática al cerrar ni reinicios durante una emisión.
- Comprobación de gráficos al aire y cambios pendientes antes de instalar.
- GitHub Actions genera y publica instaladores y metadatos de actualización.
- Builds Mac de distribución con Developer ID y notarización mediante secrets.
- Datos y logos locales conservados y excluidos del repositorio público.

Para configurar la firma y publicar la primera versión, consulta ACTUALIZACIONES.md.
La primera instalación 2.2.0 se hace manualmente; las siguientes llegan desde la app.
